Support
=======


Contribute
----------
If you are a developer and you want to submit improvements as code, you can fork
`this repo <https://github.com/marketing-factory/delete_hidden>`__
and make a pull request to the `main` branch.

Report an issue
----------------
Bugs and feature requests can be reported via the
`GitHub issue tracker <https://github.com/marketing-factory/delete_hidden/issues>`__.

For security vulnerabilities, please follow the process described in
`SECURITY.md <https://github.com/marketing-factory/delete_hidden/blob/main/SECURITY.md>`__
instead of filing a public issue.

Thanks!
